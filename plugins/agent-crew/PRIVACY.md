# Privacy policy: agent-crew

Last updated: 2026-10-09

agent-crew is a Claude Code mod that draws a pane showing which agents are working in your own session.

- It does not collect, store or send any personal data.
- It makes no network requests and talks to no service of its own.
- It reads no files, settings, environment variables or credentials.
- What it shows (agent names, the tool each one is using, timings) stays in memory inside your Claude Code session and is discarded when the session ends.

Questions: open an issue at https://github.com/abelgonzalezr/agent-crew/issues
